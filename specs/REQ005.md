# Transaction view

I want to be able to click on every transaction from the transactions/ page and see its details, both transaction (ingested) and corresponding emma stuff. I want this view to be completely read only and display everything there is to know about this transaction - including its classifications relevant for overview page graphs.

----

Q: Should the detail view show the computed graph treatment: included/excluded, contribution amount, stack category/account, and the reason (rule, account flag, currency, source state)?
A: Show stored classifications only - Display category, account, type, currency, and source data without computing an eligibility explanation.
Q: Should the read-only detail view include the full stored `raw_data` JSON, in addition to the mapped Emma fields and import timestamps?
A: Yes, include raw payload - Show a collapsible formatted source record for audit/debugging.
Q: How should a transaction open from the list?
A: transaction should be opened in a new tab with transaction/<id> url
